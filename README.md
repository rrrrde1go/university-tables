## Описание:
Приложение необходимо для автоматизации анализа конкурсных ситуаций
и распределения абитуриентов при поступлении в вуз. Оно получает список 
абитуриентов подавших документы на конкретный день и распределяет их по
направлениям учитывая приоритет и баллы, в зависимости от этих данных
расчитывается проходной былл на направление. Так же приложение имеет
функцию создания отчетов в формате pdf.

## 2) Инструкция по установке
Чтобы запустить наше веб-приложение, вам необходимо иметь установленный на вашем
компьютере язык программирования python. После вам необходимо запустить файл back_app.py.
После запуска вы можете открыть в браузере ссылку http://127.0.0.1:5000.
